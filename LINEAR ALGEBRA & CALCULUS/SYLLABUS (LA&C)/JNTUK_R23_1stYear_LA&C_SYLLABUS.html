🎯 Course Outcomes
CO1 Solve systems of linear equations using matrix methods. ▼
Understand and apply matrix rank, Echelon form, Normal form, Gauss elimination, Jacobi and Gauss-Seidel iterative methods to solve both homogeneous and non-homogeneous systems.
Ex: AX = B → find X using Gauss-Seidel with 3 iterations
CO2 Analyze matrices using eigenvalues and diagonalization. ▼
Compute eigenvalues and eigenvectors, apply Cayley-Hamilton theorem to find matrix inverse and powers. Diagonalize matrices and reduce quadratic forms using orthogonal transformations.
Ex: |A − λI| = 0 → λ₁, λ₂, λ₃ → eigenvectors → P⁻¹AP = D
CO3 Apply mean value theorems in engineering problems. ▼
Use Rolle's, Lagrange's, and Cauchy's mean value theorems. Expand functions using Taylor and Maclaurin series and apply them to engineering approximations.
Ex: f(x) = eˣ → Maclaurin: 1 + x + x²/2! + x³/3! + ...
CO4 Solve multivariable calculus problems and optimization. ▼
Compute partial derivatives, Jacobians, apply chain rule, total derivative. Find extreme values using Lagrange multipliers for constrained optimization problems.
Ex: J(u,v)/(x,y) = |∂(u,v)/∂(x,y)| — Jacobian determinant
CO5 Evaluate multiple integrals for area and volume. ▼
Set up and evaluate double and triple integrals. Change order of integration and use coordinate transformations (polar, cylindrical, spherical) to compute areas and volumes.
Ex: ∬ r dr dθ over polar region → Area = π r²

📌 Formula Quick Revision
MATRIX INVERSE (Gauss-Jordan)
[A | I] → Row Ops
→ [I | A⁻¹]
Augment matrix A with identity. Apply row operations to reduce A to identity. The right side becomes A⁻¹.
EIGENVALUE EQUATION
det(A − λI) = 0
Characteristic Eq.
Set the determinant of (A - λI) to zero to get the characteristic polynomial. Roots λ are eigenvalues.
TAYLOR SERIES
f(x) = Σ fⁿ(a)/n! · (x−a)ⁿ
Expand f(x) around point a. When a=0 it is Maclaurin series. Used to approximate transcendental functions.
JACOBIAN
J = |∂(u,v)/∂(x,y)|
= |∂u/∂x ∂u/∂y|
|∂v/∂x ∂v/∂y|
2×2 determinant of partial derivatives. Used for change of variables in multiple integrals and to test functional dependence.
DOUBLE INTEGRAL
∬_R f(x,y) dA
= ∫∫ f(x,y) dy dx
Integrate over 2D region R. To change order, sketch the region and re-express limits accordingly.
CAYLEY-HAMILTON
Every matrix satisfies
its own characteristic eq.
p(A) = 0
Replace λ with A in characteristic polynomial. Use this to find A⁻¹ and powers of A without direct computation.
LAGRANGE MVT
f'(c) = f(b)−f(a)
———————
b − a
There exists c ∈ (a,b) where the instantaneous rate equals average rate. f must be continuous on [a,b], differentiable on (a,b).
QUADRATIC FORM
Q = Xᵀ A X
A = symmetric matrix
Express as Q = aX² + bY² + cZ² + 2fYZ + ... Use orthogonal transformation P to diagonalize: Pᵀ A P = D.

  • Attempt well-known questions first
  • Show all intermediate steps clearly
  • Draw graphs / region diagrams neatly
  • Write formulas before applying them
